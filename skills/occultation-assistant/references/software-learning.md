# Aprendizaje acelerado de software

## Unidad didáctica

Para cada programa o etapa explicar:

1. problema científico que resuelve;
2. entradas y su procedencia;
3. modelo o algoritmo relevante;
4. supuestos;
5. decisiones que toma el observador;
6. salida y cómo se usa después;
7. controles independientes;
8. fallos detectables y límites.

Después aplicar el ciclo:

`explicación mínima → caso semilla → ejecución del usuario → auditoría → reparación local → repetición autónoma`.

## Reglas

- Trabajar sobre manual oficial, capturas y archivos reales disponibles.
- No convertir una interfaz en una lista de clics sin significado.
- No evaluar una técnica antes de mostrar al menos un caso ejecutado.
- Separar ajustes de visualización de transformaciones de datos.
- Marcar qué decisiones alteran el resultado científico.
- Conservar evidencia: configuración, archivos, figuras, discrepancias y conclusión.

## Criterio de autonomía

La herramienta se considera operativa cuando el usuario puede repetir un caso nuevo, explicar supuestos y controles, reconocer una salida no fiable y producir los archivos requeridos sin ayuda decisiva.
